* Renamed "endDate" field to "updatedDate" for better clarity
* Added several new standard Jira fields:
  * labels: Array of string labels attached to the issue
  * resolutionDate: field to track when issues are actually resolved
  * fixVersions: Versions where the issue was fixed
  * affectsVersions: Versions affected by the issue
  * dueDate: When the issue is due
  * resolution: Resolution status object
  * environment: Information about the environment where the issue occurs
  * workRatio: Work ratio information
  *  issue links with detailed relationship information:
    * Type of relationship (e.g., "blocks", "relates to")
      * Direction of the relationship (inward or outward)
      * Description of the relationship (e.g., "blocks", "is blocked by")
      * Key of the linked issue
