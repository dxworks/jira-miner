## Rules

- You do not need to make backward-compatible changes to the codebase.

## Agent skills

### Issue tracker

Issues and PRDs for this repo live as markdown files in `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default triage label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo is configured as single-context. Skills should read root `CONTEXT.md` and `docs/adr/` when present. See `docs/agents/domain.md`.
